Methodology

Raw data to baseline to transition functions to Monte Carlo to scenario probabilities to the lookup table, with the gates that stop a run.
Important

Theoretical scenario study. Not a forecast. Probabilities are conditional on assumptions listed in the Assumptions Register.

The two observed quantities that drive the path are the pre-AI trend growth rate and the observed unemployment rate; both enter the transition function as data, which is what licenses the rest of the arithmetic to call itself an inference.

The three categories, and the rule that keeps them apart

Category Definition May an analyst change it? Example here
Data (observed) Published about a closed period only by re-retrieval, which is a new dated row world GDP growth, WDI NY.GDP.MKTP.KD.ZG, 2025 = 2.92%
Inference (derived) Computed from data by a stated transformation yes, but the transformation is then reviewed code the t = 0 labour-income index normalised to 1.0
Assumption (theoretical choice) Everything else: elasticities, thresholds, reference year, tie rule only via a register edit and a changelog entry the substitution elasticity sigma_sub

Containment: an assumption never appears in a table labelled observed; a data value never appears in the register. Inheritance: a derived value takes the weakest status of its inputs, so a clean algebra on assumed parameters yields an assumption, not a fact.

What a probability here means

P(scenario | structure, parameter distributions, assumptions). It is the share of draws whose simulated state at horizon t falls in the region that the scenario files define. The distribution being averaged over is the assumption set, so:

Changing assumptions changes probabilities. The Assumptions Register is the authoritative list of those choices, and a probability is identified by the SHA-256 of the parameter file that produced it.

The interval reported next to a share is a Wilson score interval on a binomial proportion: sampling noise at N = 10,000. Structural uncertainty is reported separately, as the swing a parameter produces when moved from its low to its high bound: sensitivity.py --horizon 10 writes that table, and its largest entry (0.36, from a single diffusion-speed assumption) is about forty times the width of the sampling interval. Any reader who confuses the two has been mislead by a precision the study does not claim.

Reproducing

pip install -r 02_analysis/requirements.txt
python 02_analysis/scripts/ingest/fetch_sdmx.py --provider worldbank \
       --indicator NY.GDP.MKTP.KD.ZG --transport json --start 1990
python 02_analysis/scripts/ingest/build_processed.py          # exit 5 if a seed value is stale
python 02_analysis/scripts/ingest/test_ingest.py              # 5 ingestion contracts
python 02_analysis/scripts/model/transition_model.py          # gates G2, G3 self-check
python 02_analysis/scripts/model/run_monte_carlo.py --horizon 5 --convergence-check
python 02_analysis/scripts/model/build_lookup.py
python 02_analysis/scripts/model/sensitivity.py --horizon 10 --draws 4000
quarto render 05_website

A result is reproducible when the seed, the parameter hash, the model code hash, the baseline hash and the git commit in its sidecar all match. The code hash exists because a probability is a function of the arithmetic as much as of the parameters: the same parameter file produced materially different shares before and after the 2026-10-28 channel-normalisation fix, and a citation carrying only model_params_hash could not tell those two runs apart. Reproduce, do not re-run and hope.

Gates that stop a run

Gate Test On failure
G1 Schema every parameter has all six fields; assumption status must name a register ID refuse to run
G2 No hidden coefficients no numeric literal in the model outside a marked fixture region and a short allow-list refuse to run
G3 Rule partition every edge state receives exactly one label, and the labels are not collapsed refuse to run
G4 Convergence shares move less than half the CI width when N doubles flag as provisional
G5 Baseline vintage no model-consumed series older than 3 years, no conflict row refuse to run
G6 Label discipline every published probability carries the disclaimer block the site build
G7 Provenance sidecar present and hashes recomputed block the site build

Honest gaps in this method

  • The transition functions are chosen, not estimated; no backtest is claimed, because a backtest on five years of world aggregates would measure the calibration of a structure we invented.
  • Scenario C’s coincidence requirement is implemented as a path test over channel-crossing years. At t = 10 it stops discriminating, and the parameter that actually decides C is the fiscal-squeeze threshold. That measurement is in the scenario file, not hidden here.
  • Raw data is excluded from version control by design: the archive DOI, not this repository, is the citable container of the retrieved series.
